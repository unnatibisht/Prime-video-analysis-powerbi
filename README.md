# 🎬Prime Video Content Analysis Dashboard

An entertainment analytics dashboard designed to explore the Prime Video content catalog using titles, ratings, genres, directors, release years, countries, and content types.

### 📌 Key Metrics

- **Total Titles:** 9,655
- **Total Ratings:** 25
- **Total Genres:** 519
- **Total Directors:** 5,771
- **Start Date:** 1920
- **End Date:** 2021

### 📊 Dashboard Insights

The dashboard provides analysis of:

- Content by rating
- Content by genre
- Movies vs TV shows
- Content distribution by country
- Titles by release year
- Number of directors
- Overall catalog composition

### 🎭 Content Type

The dashboard compares:

- 🎥 Movies
- 📺 TV Shows

Movies represent the majority of the available titles in the analyzed dataset.

### ⭐ Rating Analysis

Content is distributed across ratings such as:

- 13+
- 16+
- All
- 18+
- R
- PG-13
- 7+
- PG
- NR

### 🎬 Genre Analysis

Major genres represented include:

- Drama
- Comedy
- Drama, Suspense
- Comedy, Drama
- Animation, Kids
- Documentary
- Kids
- Action, Drama

### 🌎 Geographic Analysis

A map visualization is used to analyze the distribution of Prime Video titles across countries and regions.

### 🎯 Business Questions

This dashboard helps answer:

- What types of content dominate the catalog?
- Which genres have the most titles?
- How does the catalog vary by rating?
- How many movies versus TV shows are available?
- How has content volume changed over the years?
- Which countries contribute the most titles?
